# Machinista navigation artwork

Eight original pictograms for the MK3 / Maschine+ color displays, generated with
the built-in image generation tool on 1 November 2026. Orange and near-white
shapes on transparent backgrounds; no manufacturer artwork or labels.

Files: pin.png, ideas.png, song.png, mixer.png, browse.png, events.png,
live-fx.png and back.png. Each is 76 x 76 RGBA, with artwork fitted inside a
68 x 68 area. Screen labels are drawn separately by the renderer.

The source prompts are recorded in prompts.json. The high-resolution generation
outputs and visual review are retained locally under output/mk3-navigation-20261101,
not included in the public source payload. Cached assets are loaded through
app/navigation_art.py; only the selected icon's brightness changes.
